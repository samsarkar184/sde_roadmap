# Software Development Roadmap

A self-contained HTML/CSS/JavaScript learning roadmap for becoming a software engineer.

## Features

- Ordered learning path
- 14 stages
- 100+ topics
- Tools and technologies
- Projects for every stage
- Search
- Category filters
- Expand/collapse stages
- Progress tracking
- "Recommended Next" indicator
- Browser localStorage persistence
- Responsive design

## Run

Open `index.html` in any modern browser.

No installation or server is required.

## Suggested path

Programming → Git/Tools → Web → Frontend → Backend → Databases → Security → Testing → Linux → Docker → CI/CD → Advanced Backend → System Design → Cloud/Career
